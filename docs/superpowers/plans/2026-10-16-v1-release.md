# WinSearch v1 self-contained Windows release plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Assemble a runnable x64 distribution, verify installation and native app behavior outside the checkout, and supply honest acceptance evidence for the v1 PR.

**Architecture:** Keep the unpackaged WinUI application with self-contained .NET/Windows App SDK, a sibling engine directory containing every Rust worker and native dependency, and a per-user Inno Setup installer. A deterministic manifest records versions/hashes/notices. Publishing/signing is a documented external operation, not fabricated by local scripts.

## Global Constraints

- Work only in C:\Users\kevin\.codex\worktrees\winsearch-v1\WinSearch on codex/winsearch-v1. All approved extraction/PDF/media/code/shell/retrieval tasks must first pass review.
- Prefix shell commands with rtk. Preserve original and prior dirty checkouts, test thresholds, reference vectors and real-model fail-closed behavior.
- Test only generated/public synthetic content with isolated data/instance identifiers. Do not alter an existing user's installation, startup value, personal index or source documents.
- Produce local unsigned artifacts honestly. Do not publish a release/feed, purchase a certificate, invent secrets, merge a PR or change repository protection settings.
- Installed execution must succeed without source-tree paths, developer PATH, a globally installed .NET runtime or a development SDK. No silent missing-worker fallback.
- No blanket v1 readiness claim while required runtime gates remain unverified. Unsupported test hardware is named explicitly.
